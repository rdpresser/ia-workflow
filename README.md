# AI Taskflow

This project is a proof of concept (PoC) created to study Python and modern backend tooling.

## Project Goal

The main goal is to experiment with Python development practices, dependency management with Poetry, and integrations with AI-related libraries.

## Main Dependencies

- FastAPI
- Uvicorn
- SQLAlchemy
- Alembic
- psycopg2-binary
- Redis
- PyJWT
- Requests
- Google Cloud Pub/Sub
- LangChain
- langchain-openai
- langchain-anthropic

## Development Dependencies

- pytest
- pytest-asyncio
- ruff
- mypy
- pre-commit
